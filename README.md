# Neurosurgery Digest

Каждый понедельник в 09:00 МСК GitHub Actions ищет новые записи PubMed за последние 7 календарных дней и отправляет до 10 публикаций по выбранным направлениям в Telegram.

Настроены три направления: сосудистая нейрохирургия (внутричерепные аневризмы, АВМ, каверномы ЦНС), хирургия позвоночника и спинного мозга, нейротравма (ЧМТ и повреждения спинного мозга). Отбор чередует направления: обычно 4/3/3 при достаточном числе работ; при нехватке в одной теме используются другие выбранные темы. Одна публикация с несколькими темами включается один раз. Под каждой работой указаны темы. Общая нейрореанимация отдельно больше не ищется; она попадает в подборку в контексте выбранных заболеваний и травм. Если работ меньше восьми, бот явно сообщает об этом. Дата отбора — поступление записи в PubMed, а дата самой публикации может быть раньше. При нагрузке GitHub запуск по расписанию может задержаться.

## Telegram

Используются существующий Secret `TELEGRAM_BOT_TOKEN` и Variable либо Secret `TELEGRAM_CHAT_ID` (приоритет у Secret). Бот должен быть запущен получателем командой /start. После изменения кода в main автоматически отправляется одно тестовое сообщение. Полный дайджест запускается по расписанию или через Actions → Neuro Digest → Run workflow → digest. Режим telegram-test проверяет только доставку.

## Бесплатный ИИ — необязательно

OpenAI полностью исключён, его ключ не используется. Gemini подключается через Secret `GEMINI_API_KEY` автоматически при наличии ключа. Variable `GEMINI_FREE_TIER=false` отключает ИИ. Используйте ключ проекта Google AI Studio без подключённого платёжного аккаунта и с доступным бесплатным тарифом в вашем регионе. Сам код не может проверить наличие биллинга: ключ платного проекта использовать нельзя. Необязательная Variable `GEMINI_MODEL` меняет модель (по умолчанию gemini-2.5-flash-lite). Актуальная доступность и квоты зависят от Google.

Без ключа, при отключённом бесплатном тарифе, ошибках, блокировке или исчерпании квоты бот автоматически переходит на режим без генеративного ИИ. Он отдельно извлекает цель и методы, результаты, явно указанные ограничения и заключение авторов из аннотаций и пробует перевести их на русский бесплатным веб-сервисом Google Translate без ключа. Этот сервис не гарантирует доступность; при его отказе сохраняется оригинальная выдержка с русским пояснением. Перевод требует передачи текста опубликованной аннотации Google.

Резервный режим не выдаёт шаблонные замечания за ограничения авторов или самостоятельную клиническую оценку. Он прямо сообщает, что ограничения конкретной работы и применимость требуют проверки полного текста. Полный русскоязычный анализ обеспечивает доступный Gemini; без внешних сервисов гарантировать перевод научных аннотаций невозможно.

## Проверки и ошибки

Перед отправкой Actions проверяет синтаксис, зависимости и unit-тесты. Успех отправки фиксируется только после ответа Telegram с message_id и совпадением получателя. Это подтверждает принятие сообщения Telegram, но не его прочтение человеком. При сетевом тайм-ауте отправка не повторяется автоматически, поскольку сообщение уже могло быть принято. Для 429 учитывается retry_after. Секреты, тексты исключений HTTP и URL Telegram не печатаются.

Система анализирует аннотации, не полные тексты, и не заменяет клиническое решение. Постоянного журнала PMID пока нет: ручные повторные запуски и повторное индексирование могут привести к повторам.

Локальная проверка: `python -m pip install -r requirements.txt`, `python -m pip check`, `python -m py_compile main.py`, `python -m unittest discover -s tests -v`.

## OpenRouter вместо Gemini

Secret `OPENROUTER_API_KEY` автоматически включает OpenRouter как первый сервис.
Получить ключ: https://openrouter.ai/settings/keys. Сохранить его: Settings → Secrets and variables → Actions → New repository secret.
Используется строго `openrouter/free`: платные модели и платные резервные маршруты не задаются.
При ошибке или исчерпании бесплатной квоты используется Gemini (если настроен), затем резервный режим без ИИ.
Для проверки требуется запуск digest и строка `Free OpenRouter analysis validated` в Actions; успешная отправка без этой строки не подтверждает работу OpenRouter.

## Короткий формат и отбор

Одно вступление и строго одно Telegram-сообщение на публикацию:
флаг страны журнала, название статьи на русском, первые три фамилии авторов
в порядке PubMed, один краткий вывод ИИ и ссылка на источник.
Цель исследования, дизайн и отдельный список результатов не выводятся.

ИИ переводит название и формулирует вывод по аннотации в 1–2 законченных
предложениях. Заголовок и вывод ограничены 420 символами каждый.
Слишком длинный или незаконченный ответ отклоняется для повторной генерации:
обрезания по символам и многоточий нет. Фамилии берутся из LastName первых
трёх индивидуальных авторов; коллективные имена не выдаются за фамилии.
При отсутствии авторов выводится соответствующее сообщение.

Если бесплатный ИИ недоступен, бот переводит название и берёт только полные
предложения из заключения/результатов авторов с пометкой «Без ИИ — вывод авторов».
Это не независимая интерпретация ИИ. Если перевод недоступен либо полное предложение
не помещается, бот честно сообщает об этом и сохраняет ссылку.

Для каждого направления просматривается до 60 свежих записей PubMed. Приоритет
получают рекомендации, рандомизированные клинические испытания, метаанализы и
систематические обзоры, затем другие клинические исследования. Описания случаев
и исследования только на животных получают меньший приоритет. Отозванные работы,
исправления, редакционные комментарии и препринты исключаются по типу PubMed.
Это предварительный отбор по дизайну и метаданным, не независимая оценка качества
полного текста. Баланс трёх направлений сохраняется.

Отдельные пункты о цели, дизайне, методах, ограничениях и клиническом значении в карточках не выводятся.
Ранжирование публикаций по типу исследования сохранено только для внутреннего отбора.

Флаг перед названием статьи обозначает страну издания журнала из поля PubMed
`MedlineJournalInfo/Country`. Он не обозначает гражданство авторов или страну
проведения исследования. Если страна отсутствует или не распознана, выводится 🌐.

# Neurosurgery Digest

Каждый понедельник в 09:00 МСК GitHub Actions ищет новые записи PubMed за последние 7 календарных дней и отправляет до 10 публикаций по нейрохирургии и нейрореанимации в Telegram. Если работ меньше восьми, бот явно сообщает об этом. Дата отбора — поступление записи в PubMed, а дата самой публикации может быть раньше. При нагрузке GitHub запуск по расписанию может задержаться.

## Telegram

Используются существующий Secret `TELEGRAM_BOT_TOKEN` и Variable либо Secret `TELEGRAM_CHAT_ID` (приоритет у Secret). Бот должен быть запущен получателем командой /start. После изменения кода в main автоматически отправляется одно тестовое сообщение. Полный дайджест запускается по расписанию или через Actions → Neuro Digest → Run workflow → digest. Режим telegram-test проверяет только доставку.

## Бесплатный ИИ — необязательно

OpenAI полностью исключён, его ключ не используется. Gemini подключается через Secret `GEMINI_API_KEY` только при Variable `GEMINI_FREE_TIER=true`. Используйте ключ проекта Google AI Studio без подключённого платёжного аккаунта и с доступным бесплатным тарифом в вашем регионе. Сам код не может проверить наличие биллинга: ключ платного проекта использовать нельзя. Необязательная Variable `GEMINI_MODEL` меняет модель (по умолчанию gemini-2.5-flash-lite). Актуальная доступность и квоты зависят от Google.

Без ключа, при отключённом бесплатном тарифе, ошибках, блокировке или исчерпании квоты бот автоматически переходит на режим без генеративного ИИ. Он извлекает предложения с результатами из аннотаций и пробует перевести их на русский бесплатным веб-сервисом Google Translate без ключа. Этот сервис не гарантирует доступность; при его отказе сохраняется оригинальная выдержка с русским пояснением. Перевод требует передачи текста опубликованной аннотации Google.

Резервный режим не выдаёт шаблонные замечания за ограничения авторов или самостоятельную клиническую оценку. Он прямо сообщает, что ограничения конкретной работы и применимость требуют проверки полного текста. Полный русскоязычный анализ обеспечивает доступный Gemini; без внешних сервисов гарантировать перевод научных аннотаций невозможно.

## Проверки и ошибки

Перед отправкой Actions проверяет синтаксис, зависимости и unit-тесты. Успех отправки фиксируется только после ответа Telegram с message_id и совпадением получателя. Это подтверждает принятие сообщения Telegram, но не его прочтение человеком. При сетевом тайм-ауте отправка не повторяется автоматически, поскольку сообщение уже могло быть принято. Для 429 учитывается retry_after. Секреты, тексты исключений HTTP и URL Telegram не печатаются.

Система анализирует аннотации, не полные тексты, и не заменяет клиническое решение. Постоянного журнала PMID пока нет: ручные повторные запуски и повторное индексирование могут привести к повторам.

Локальная проверка: `python -m pip install -r requirements.txt`, `python -m pip check`, `python -m py_compile main.py`, `python -m unittest discover -s tests -v`.
